GT7 Dash — Windows 便携版
=========================

本包含三个程序（免安装、绿色）：
  gt7-dashboard.exe   Web 仪表盘：浏览器里看实时遥测 + 历史场次
  gt7-recorder.exe    遥测接收器：接收 PS5 的 UDP 遥测并按场次落盘
  gt7-decrypt.exe     Salsa20 解密器：接收器会自动调用，请勿删除或改名

快速开始
--------
1) 让 PS5 与这台电脑处在同一个局域网（同一网段；不要隔访客 WiFi 或 AP 隔离）。
2) PS5 上打开《GT7》→ 设置 → 网络，开启遥测发送。
3) 双击 run-recorder.bat 启动接收器（窗口保持开着）。
4) 双击 run-dashboard.bat 启动仪表盘，浏览器打开 http://127.0.0.1:8787
5) 进游戏把车开上赛道，数据即会出现。

数据放在哪
----------
采集到的场次和状态文件都在本目录下的 data\ 文件夹里。场次是 .jsonl 文本，
可直接备份，也可用别的程序按公开 API 文档解析。

常见问题
--------
- 收不到数据：确认同一网段、GT7 遥测已开、Windows 防火墙放行 gt7-recorder.exe。
- 仪表盘显示「未连接」：接收器没在跑，或 PS5 没在发数据（停在菜单/停车场不会记录）。
- 端口被占用：仪表盘默认 8787，可编辑 run-dashboard.bat 里的 --port 换端口。
- 控制台出现 ? 或乱码：属正常，中文/符号在部分终端编码下会显示为 ?，不影响功能。
