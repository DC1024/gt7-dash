# GT7 Dash

**PS5《Gran Turismo 7》官方 UDP 遥测 → 本地 Salsa20 解密 → Web 实时仪表盘 + 公开数据 API。**

单文件服务、Docker 一键部署、全部数据本地处理、不依赖任何第三方服务。
默认跑在局域网里，不上公网。

## 它能干什么

- **实时仪表盘**：转速 / 速度 / 档位 / 踏板 / G 力球 / G-G 图 / 四轮温度 /
  **前轮转角** / **逐轮路面** / 圈速列表，60Hz 渲染，卡片可拖拽排序
- **历史场次**：进赛道自动开始、回菜单自动结束；每场都能看圈速、逐帧曲线、
  行车轨迹、分段计时、走线偏差、轮胎滑移
- **10 类驾驶事件**：打滑 / 碰撞 / 极限刹车 / 轮胎滥用 / 大油门 / 出界 /
  超车·被超 / 进站 / 最快圈 / 压路肩，可导出集锦剪辑时间轴
- **公开 API**：40 个端点，带 CORS，字段与单位写进文档，版本化承诺只加不改
- **赛道识别**：GT7 不下发赛道名，按轨迹的几何指纹自己认

## 五分钟跑起来

```bash
mkdir gt7-dash && cd gt7-dash
curl -O https://raw.githubusercontent.com/DC1024/gt7-dash/main/docker-compose.yml

# 🔴 先建 data 并交给容器用户（uid 10001）。镜像里的 chmod 会被 bind mount
#    遮住，不授权的话首次启动写不了文件 —— status.json 静默失败、
#    录制器打不开 jsonl 会直接退出。
mkdir -p data && sudo chown 10001:10001 data

docker compose up -d
# 打开 http://<本机IP>:8787
```

PS5 侧只需要：**设置 → 网络 → 打开 GT7 遥测上传**（UDP 33739 / 33740 在同一网段）。

## 一句话说清它跟别的不一样在哪

GT7 的 UDP 遥测**没有官方文档**，社区文档有三处是错的，本项目全部用真机抓包
逐字节对拍纠正过：

1. **路面类型** `surfaceType[4]` 不是 `int32[4]`，是 **4 个 ASCII 字符**
   （`T` 铺装 / `C` 路肩 / `G` 草地 / `s` 砂石）
2. **格式 C 的解密 mask 是 `0xDEADBEEF`**，A/B/`~` 是 `0xDEADBEAF` —— 差一个字母
3. **`quali_pos`（`0x84`）在比赛中就是当前名次**，不是"发车位"

还有一条是"知道做不到"：`~` 包（344B）确认存在但换了 key/nonce，**解不开**，
于是明确标注不支持，而不是编一组看起来合理的数字。
