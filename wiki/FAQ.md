# FAQ

## 收不到数据

1. PS5 与运行本服务的机器必须**同一网段**，且 PS5 已开启
   **设置 → 网络 → GT7 遥测上传**
2. 防火墙放行 **UDP 33739 / 33740**（A 包走 33739，B/C 走 33740）
3. 仪表盘顶部「包格式」计数在涨但「采样」为 0 → 车没开动。
   速度 ≥15 km/h 且 ≥30 帧才开始记录

## 重启容器后就没数据了

包类型在「**进入赛道**」那一刻锁定。recorder 重启会重新发心跳，但游戏在
赛道里不会理你 —— **退出赛道，回菜单，再重新进一次**。

这条也解释了另一个坑：在赛道里改 `--packet-type` 完全不生效。
实测在赛道里依次换 A→`~`→B→C 各 90 秒，四段收到的全是 296B 的 A 包。

## 左转时 G 力球往右漂，是不是标反了？

不是。球画的是**离心方向** —— 你被甩向弯外的那一侧，和真车体感一致，
也和界面上那个「碗」的比喻一致（车往左转，球被甩到碗的右边）。

数值口径是「**横向 G 为正 = 左转**」。实测依据：GT7 是右手系
（`corr(dθ/dt, ω_y) = −0.93`），而横向基向量指向左侧；独立验证 ——
左转时右侧两轮走外圈、转得更快（`corr = +0.40`）。

🔴 别去翻这个符号：一翻，G-G 图、事件里的转弯曲率、方向盘转角的符号会跟着全错。

## 没有「前轮转角」这一行 / 「路面」这一行

两者都**只有格式 C** 才有（`0x160`/`0x164` 和 `0x158`）。默认请求的就是 C，
所以先检查有没有手动改过 `GT7_PACKET_TYPE`。

另外 `~` 包解不开、B 包没有路面 —— 切过去这些行会消失，这是预期的。

## 路面显示出没见过的字母

正常的。GT7 的路面字符不止 `T`/`C`/`G`：实测还有小写 `s`（砂石 / 泥地，
整场都是 `ssss` 的拉力赛道）。没见过的字符会**照原样显示**（棕色格子），
右侧读数给「非铺装」，不会变成问号。

## 为什么 A 包场次的压路肩事件是 0 条？

因为 A/B/`~` 包里**没有路面字段**。检测器在这种情况下**一条都不报**，
而不是给个默认值假装"没压过" —— 把"没有数据"伪装成"开得干净"是更坏的结果。

## 暂停时数据不动

正常。GT7 暂停时物理冻结但仍以上报（速度 0 / 怠速），界面会显示
「⏸ 游戏已暂停 —— 以下数值是 GT7 暂停时的上报值」。

## 赛道名字认错了 / 显示「自动识别·待确认」

正常 —— 名字是按圈长猜的，圈长相近的不同赛道确实会猜错。
去 `/tracks` 改成正确的名字点「保存」，同赛道所有场次会一起更正。
形状图（几何指纹）本身不会认错，认错的是名字。

## 车型显示成 `CAR-ID-3656`

那是社区车型表还没收录的车。数字码是 GT7 自己在包里下发的，一定准；
缺的只是「码 → 名字」这张表。在数据目录放一张 `data/cars_extra.csv` 就能补：

```csv
ID,ShortName,Maker
3656,Xiaomi Vision Gran Turismo,
```

## 历史场次里的记录消失了

先看回收站（页面下方）。异常场次（没有完成圈 / 唯一圈 <20s 的菜单残片）
会在加载时自动移到回收站，保留期内可一键恢复。

## 想锁定 PS5 的 IP

compose 的 recorder 命令里加 `--ps5 192.168.x.x`（默认 `auto` 自动发现）。

## 能不能从公网访问？

不建议，而且默认就不支持：只绑内网、没有鉴权，靠 Host 白名单 + 同站校验
防跨站写入。要远程看就上 WireGuard / Tailscale。

## API 会不会改字段名？

`/api/v1/*` 的字段名与单位是**对外承诺**：只新增，不改名、不改单位。
内部怎么重构都行，适配层在 `_v1_live` 里。
