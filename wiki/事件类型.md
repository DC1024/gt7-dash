# 事件类型

仪表盘会从遥测里**离线**检测驾驶事件，按圈展开在「驾驶事件时间线」卡片里，
同时可以通过 `GET /api/v1/sessions/<文件名>/events?lap=N` 拿到。

事件不是"标记"出来的，是每次展开时按判据重算的（结果记忆化到内存，
改阈值会自动失效重算）。

## 10 类事件

| 类型 | 中文 | 判据 | 备注 |
|---|---|---|---|
| `collision` | 碰撞 | 纵向 G 强负（< −2.2g）且伴随速度突变 | 权重最高 |
| `spin` | 打滑 / 失控 | 横向 G > 1.05g **且**滑移率高 | |
| `hard_braking` | 极限刹车 | 刹车 > 85% 且车速 > 130 km/h | |
| `off_track` | 出界 | 走线偏差 `\|dlat\| > 5m` 为主；无几何参照时退回「低速 + 高滑移」 | |
| `tyre_abuse` | 轮胎滥用 | 单轮滑移率显著高于其他三轮 | 与 `spin` 分开，别混 |
| `heavy_throttle` | 大油门出弯 | 全油门 > 0.5s，且速度在 60~上限区间、档位 ≥2 | 有速度**上限**，否则直道全油门会淹没时间线 |
| `overtake` | 超车 / 被超 | 遥测名次 `quali_pos` 变化，排除进站窗口 | 不需要截图 OCR |
| `pit_like` | 进站 | 油量环跳（强）+ 长时间低速（弱） | 区分「暂停」和「维修区通行」 |
| `lap_record` | 最快圈 | 本圈官方 `last_lap_ms` 刷新个人最好 | 只用 `time_source == official` 的圈 |
| `tank_slap` | **压路肩** | 连续 ≥0.2s、车速 ≥30km/h、至少一轮 `surface` 含 `C` | **需格式 C** |

## 压路肩（`tank_slap`）为什么这么设计

数据源是 `0x158` 的逐轮路面（4 个字符，`T` 铺装 `C` 路肩 `G` 草地 `s` 砂石）。

- **只有 `G` 没有 `C`** → 那是纯出界，交给 `off_track`，这里不重复报
- **`C` 和 `G` 混着** → 报压路肩，并在证据里标「同时压到草地」
- **整场没有 `surface` 字段**（A/B/`~` 包）→ **一条都不报**

最后一条最容易写错：如果给个默认值 `"TTTT"`，A 包场次会永远显示
「零次压路肩」，把**没有数据**伪装成**开得干净**。

证据长这样：

```json
{
  "压路肩轮数": 2,
  "路面": "TCTC",
  "持续_s": 1.02,
  "均速_kph": 131.4,
  "同时压到草地": true
}
```

置信度 = `0.45 + 0.12 × 轮数 + 0.25 × 持续秒数`（封顶 1.0）。
压一下就走的抖动落在 0.5 左右，四轮齐上且持续半秒以上才接近 1。

## 阈值可以自己调

常用阈值能在事件卡里直接改（存 `settings.json`，不用改源码重启）：

- 打滑：`spin_lat_g`、`spin_slip_ratio`
- 碰撞：`impact_long_g`
- 极限刹车：`hard_brake_throttle`、`hard_brake_min_speed`
- 出界：`offtrack_max_speed`、`offtrack_slip`
- 超车：`overtake_margin`
- 压路肩：`curb_min_speed`、`curb_min_duration`

接口：`POST /api/v1/settings/event-thresholds`，body `{"values": {"spin_lat_g": 1.2}}`，
传 `null` 表示恢复该键默认；未知键或非数字返回 400。

## 集锦高光

`GET /api/v1/sessions/<文件名>/highlights` 把事件按
**置信度 × 类型权重**排序，给出可直接喂 ffmpeg 的 `clip_start` / `duration`
（前后各留白），以及录像时间轴上的对应秒数。

| 类型 | 权重 |
|---|---|
| 碰撞 | 10 |
| 打滑 | 8 |
| 出界 | 7 |
| 最快圈 | 6.5 |
| 超车 | 6 |
| 轮胎滥用 | 5 |
| 大油门 | 4 |
| 极限刹车 | 3 |
| 进站 | 2 |
| 压路肩 | 1.5 |
